# Flappy Bird для OpenCode Desktop

Небольшой Flappy Bird в боковой панели OpenCode Desktop. Открывается сам, пока агент работает.

[English version](README.md)

## Возможности

- Открывается примерно через секунду после старта агента и закрывается после завершения, но не посреди игры
- Физика с фиксированным шагом 120 Гц и интерполяцией, заранее отрисованные спрайты, около 0,1 мс на кадр
- В простое не тратит процессор: отрисовка останавливается на паузе, после проигрыша и когда панель или окно скрыты
- Пауза по `P`, по клику мимо игры или при скрытии панели, игра продолжается с того же места
- Табло со счётом, рекордом и медалями за 10, 20, 30 и 40 очков
- Плашка статуса агента: «Агент работает…» и «Агент закончил»
- Русский и английский интерфейс

## Требования

- OpenCode Desktop 2.2 или новее, плагин использует экспериментальный API GUI-плагинов
- Терминальный интерфейс не поддерживается

## Установка

### npm

```sh
opencode plugin add opencode-flappybird
```

Или добавьте пакет в глобальный конфиг `~/.config/opencode/opencode.json`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["opencode-flappybird"]
}
```

OpenCode Desktop загружает GUI-плагины только из глобального конфига. После установки плагин появится в **Settings → Extensions → Plugins**.

Если установлен только OpenCode Desktop, команды `opencode` может не быть в `PATH`. Тогда отредактируйте конфиг или попросите агента в OpenCode установить `opencode-flappybird`.

### GitHub

```sh
opencode plugin add github:OWNER/REPO
```

## Использование

- Наберите `/flappy` в поле ввода, выполните **Играть во Flappy Bird** из палитры команд или выберите **Flappy Bird** в меню `+` боковой панели
- Клик, `Пробел`, `↑`, `W` или `Enter` — взмах, `P` — пауза
- Горячую клавишу можно назначить в **Settings → Shortcuts**

## Настройки

```jsonc
{
  "plugins": [
    {
      "package": "opencode-flappybird",
      "options": { "autoOpen": false, "autoClose": false }
    }
  ]
}
```

| Опция       | По умолчанию | Описание                                                   |
| ----------- | ------------ | ---------------------------------------------------------- |
| `autoOpen`  | `true`       | Открывать игру, пока агент работает                        |
| `autoClose` | `true`       | Закрывать автоматически открытую игру после завершения агента |

## Разработка

Плагин — один CommonJS-файл `gui-experimental.cjs` без сборки. Чтобы проверить локальные изменения, укажите путь к папке в массиве `plugins` глобального конфига. После каждого сохранения OpenCode перезагружает плагин во всех окнах.
