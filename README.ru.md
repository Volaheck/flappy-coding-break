# Flappy Coding Break

Играй во Flappy Bird, пока агент пишет код. Один репозиторий, общая игра и три интеграции.

[English](README.md)

| Приложение | Где работает игра | Управление |
| --- | --- | --- |
| OpenCode Desktop 2.2+ | Родная боковая панель, исходная Canvas-графика | Клик, Space, ↑, W, Enter; P — пауза |
| Claude Code Terminal / Desktop | Родная панель Mods: сцена и HUD как в Canvas-версии в Desktop, пиксельная графика в терминале | Клик, W или Space в активной игре; P — пауза |
| Codex Desktop с MCP Apps UI | Встроенное приложение в панели чата, Canvas-графика | Клик, Space, ↑, W, Enter; P — пауза |

Внешние окна и браузер не открываются. Терминальный Codex и расширение Claude Code для VS Code не предоставляют используемую здесь игровую панель.

## Установка

Используй штатный менеджер плагинов своего приложения. Для команд терминала CLI выбранного приложения должен быть в `PATH`; в Codex Desktop можно установить плагин через интерфейс.

### OpenCode Desktop

```sh
opencode plugin add github:Volaheck/flappy-coding-break
```

Нужен OpenCode Desktop 2.2+. После установки перезапусти Desktop или перезагрузи плагин. См. [документацию плагинов OpenCode](https://dev.opencode.ai/v2/docs/plugins#manage).

Имя npm-пакета сохранено: `opencode-flappybird`. После публикации соответствующей версии команда `opencode plugin add opencode-flappybird` продолжит работать. Экспорт `./gui-experimental` по-прежнему указывает на один готовый CommonJS-файл.

### Claude Code

```sh
claude plugin install flappy-coding-break --marketplace Volaheck/flappy-coding-break
```

Команда добавляет marketplace и устанавливает плагин за один шаг. Нужен Claude Code 2.1.292+. После установки начни новую сессию.

Можно установить прямо внутри Claude Code:

```text
/plugin install flappy-coding-break --marketplace Volaheck/flappy-coding-break
```

Команда внутри сессии поддерживается с версии 2.1.275 и предлагает подтвердить marketplace и область установки. См. [документацию плагинов Claude](https://code.claude.com/docs/en/discover-plugins#add-a-marketplace-and-install-in-one-command).

### Codex Desktop

Открой **Plugins → Add → Add a marketplace**. В поле **Source** укажи `Volaheck/flappy-coding-break`, нажми **Add marketplace**, затем **Install** у **Flappy Coding Break**.

Другой вариант — терминал, если команда `codex` доступна в `PATH`:

```sh
codex plugin marketplace add Volaheck/flappy-coding-break
codex plugin add flappy-coding-break@flappy-coding-break
```

Если терминал сообщает `command not found: codex`, CLI недоступен в `PATH`. Используй интерфейс Desktop по инструкции выше либо установи и настрой CLI перед выполнением команд.

В Codex установка состоит из двух штатных шагов: один раз добавить marketplace, затем установить плагин по имени. Флаг `plugin add --marketplace` принимает имя уже добавленного marketplace, а не адрес GitHub-репозитория. См. [справочник команд Codex](https://learn.chatgpt.com/docs/developer-commands#codex-plugin).

Для локального MCP-сервера нужен Node.js 20+ в `PATH`, а для игры — desktop-версия Codex с MCP Apps UI. После установки перезапусти приложение. Проверь и разреши хуки плагина через `/hooks` в CLI или настройки хуков приложения. Установка плагина сама по себе не выдаёт доверие хукам; после изменения их определений может потребоваться повторная проверка.

### Дополнительно: установка в несколько приложений сразу

Вспомогательный установщик на Node.js 20+ запускает те же штатные команды и перед установкой проверяет все выбранные CLI. Для `--all` все три CLI должны быть в `PATH`; отдельные приложения выбираются флагами `--opencode`, `--claude` и `--codex`.

```sh
npx github:Volaheck/flappy-coding-break install --all
```

Плагин ставится в постоянные каталоги родных менеджеров, существующие настройки сохраняются, временная папка `npx` не нужна для дальнейшей работы. Посмотреть команды или проверить поддержку CLI без установки:

```sh
npx github:Volaheck/flappy-coding-break install --all --dry-run
npx github:Volaheck/flappy-coding-break doctor --codex
```

## Использование

Открытие новой панели Flappy закрывает предыдущие панели игры в этом приложении, в том числе из других чатов. Другие приложения и посторонние панели не затрагиваются. Codex и Claude проверяют активную панель раз в секунду без вызовов модели; приостановленная самим приложением панель сможет закрыться после возобновления. Панели старых версий должны загрузить обновление, чтобы участвовать в этом механизме.

Когда агент заканчивает ответ, текущая партия сразу завершается, в том числе на паузе. Итоговый счёт сохраняется и учитывается в рекорде, даже если птица не погибла. Панель остаётся открытой с текущим и лучшим результатом. Начать или продолжить игру можно только после того, как агент снова начнёт работать; следующий клик или клавиша взмаха запускает новую партию.

Прежняя настройка `autoClose` больше не используется. Панель результатов можно закрыть вручную.

### OpenCode

Введи `/flappy`, выбери **Play Flappy Bird** в палитре команд или **Flappy Bird** в меню `+` боковой панели. Игра открывается примерно через секунду работы агента. Каждый чат хранит собственную партию и результаты.

Автооткрытие настраивается в глобальном конфиге OpenCode:

```jsonc
{
  "plugins": [
    {
      "package": "github:Volaheck/flappy-coding-break",
      "options": { "autoOpen": true }
    }
  ]
}
```

### Claude Code

Команда `/flappy` открывает и закрывает родную панель, в том числе во время работы Claude. Автооткрытие привязано к основному агенту. Завершение его ответа заканчивает партию и показывает сохранённый счёт и рекорд; завершение подагента на партию не влияет.

Отрисовка использует Mods Client API и общую физику, без браузера: графика и HUD как в Canvas-версии в Desktop (SVG-фон и плавно движущееся поле) и пиксельная графика в терминале. В настройках плагина доступны `autoOpen` и `locale` (`en` / `ru`).

В терминале автооткрытие зависит от ширины: обычно нужно от 144 колонок, либо от 110 после ручного открытия панели. В узком терминале используй `/flappy`. Стрелки зарезервированы интерфейсом; для игры есть W, Space и указатель. В расширении VS Code нужный элемент Client недоступен.

### Codex

Попроси **«Открой Flappy Bird»**, вызови навык `flappy` или выбери **Flappy Bird** среди приложений панели чата. Инструмент `open_flappy` возвращает встроенную игру; можно продолжать задачу с игрой рядом.

Разрешённые хуки просят открыть игру в начале каждого нового ответа агента, даже если её уже открывали в этом чате. Открытие выполняется одним вызовом инструмента за ответ; дальнейшая игра и обновление статуса не вызывают модель. Статус читается только для текущего чата через MCP-инструмент, доступный интерфейсу игры. Внешних сетевых запросов нет.

Завершение ответа, прерывание и завершение сессии заканчивают партию и блокируют игру, оставляя результаты на экране. Новый ответ агента снимает блокировку. Потеря связи со статусом не разблокирует завершённую игру. После ручного закрытия панель можно открыть навыком, через выбор панели или при следующем ответе агента. «Ответ готов» не означает, что вся задача завершена: другой хук может продолжить работу.

Статус определяется текущим ответом в этом чате. Начало нового ответа заменяет устаревшие записи от пропущенного сигнала остановки; запоздалый сигнал от старого ответа не останавливает новый. Чтобы завершение доходило до игры, хуки должны оставаться включёнными и разрешёнными.

Для статуса нужны разрешённые хуки и поддерживаемое локальное выполнение Codex. Без хуков играть можно, но живой статус недоступен. Нужна desktop-версия с MCP Apps UI; установка только в CLI не добавляет графическую панель.

## Разработка

```sh
npm run build
npm test
npm run check:generated
npm run test:claude
npm pack --dry-run
```

Внешних npm-зависимостей для работы нет. Общая физика — `game/core.cjs`, Canvas-отрисовка — `game/canvas.cjs`, переводы — `game/i18n.cjs`. Интеграции расположены в `adapters/`.

`test:claude` скачивает закреплённую версию официального CLI Claude Code и запускает его валидатор плагинов и родной набор тестов в отдельном временном профиле. Нужен доступ к сети; аккаунт и вызовы модели не нужны. CI также проверяет Node-тесты и сборку на Linux и Windows с Node.js 20 и 24.

Сборка создаёт `gui-experimental.cjs` для OpenCode, `web/game.js` для встроенной игры Codex и ESM-версию ядра/переводов для песочницы Claude. Изменяй исходники и запускай сборку; сгенерированные файлы вручную не редактируются.

Локальная установка в Claude/Codex:

```sh
node bin/flappy.js install --claude --codex --source .
```

Исходная папка должна оставаться доступной. `--source` меняет marketplace Claude/Codex; `--opencode-source` отдельно задаёт npm/Git-пакет OpenCode. Для локальной разработки OpenCode добавь абсолютный путь репозитория в `plugins` глобального конфига и пересобирай после изменений.

Тесты проверяют физику, события приложений, MCP-протокол, разделение статусов разных чатов, сборку и установщик. Перед релизом также проверяй игру в самих приложениях, особенно после изменения экспериментальных UI API. См. [PUBLISHING.md](PUBLISHING.md).
